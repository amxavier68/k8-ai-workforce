## 1. Australian eCommerce product-safety evidence

Source: Australian Competition and Consumer Commission, 2026-08-19  
URL: https://www.accc.gov.au/media-release/federal-court-upholds-14m-penalty-in-accc-case-against-city-beach

Affected leads: Renee, Sentinel, Clarity, Atlas

Change: eCommerce discovery and UX reviews should treat mandatory product-safety standards and required safety information as operational/compliance inputs, not as optional product-copy polish. The City Beach case concerned button-battery products; it does not imply that every retailer or DFG carries affected goods.

Operational effect: verify whether a client sells regulated products before recommending catalogue, marketplace or merchandising changes. Preserve the distinction between admitted conduct, court findings and allegations.

## 2. WordPress security branch awareness

Source: WordPress.org, 2026-08-12  
URL: https://wordpress.org/news/2026/08/wordpress-7-0-4-release/

Affected leads: Renee, DevMate, Sentinel, Atlas

Change: WordPress 7.0.4 is a security release for the 7.0 branch. Site advice must first identify the installed core version and compatible update path; do not downgrade a site already on 7.1 or describe 7.0.4 as the universal latest version.

Operational effect: use staging/backups and the established transaction-path test for DFG before material production updates.

## 3. Sitemap-free ingestion is not sitemap-free SEO

Source: Cloudflare, 2026-08  
URL: https://blog.cloudflare.com/ai-search-easier/

Affected leads: Renee, Clarity, Kai, Atlas

Change: Cloudflare AI Search now offers a Discover parsing option for ingesting an owned website without a sitemap. This is a vendor indexing capability for agent applications, not evidence that public search engines or client websites no longer benefit from high-quality sitemaps.

Operational effect: retain ordinary crawlability, sitemap and structured-content practices. Treat Cloudflare adoption and any associated spend as a separate Finlay/owner decision.

## 4. Browser regression cadence

Source: Chrome for Developers, 2026-03-03  
URL: https://developer.chrome.com/blog/chrome-two-week-release

Affected leads: Renee, DevMate, Mira, Atlas

Change: Chrome moves from a four-week to a two-week stable release cadence starting September 2026.

Operational effect: favour a small repeatable smoke-test path for critical customer journeys over large ad hoc browser audits. This knowledge does not itself authorize new tooling or production changes.
