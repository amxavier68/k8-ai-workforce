# K8 AI Workforce

Version-controlled source of truth for the Kollabor8 AI workforce.

This repository governs role charters, workforce manifests, behavioural commissioning contracts, permission profiles and CI/CD checks for the eight accountable K8 AI leads. Anthony remains the accountable human owner; Renee Archer remains 2iC and workforce release manager.

> Public-repository rule: never commit credentials, private client data, personal financial information, access tokens, unpublished secrets or sensitive operational data.

The workforce lifecycle is: **change request → draft → static checks → role tests → cross-seat tests → Sentinel/Mira gates → canary → commission → observe → patch/rollback**.
