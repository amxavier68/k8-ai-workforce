# Security and privacy

This is a public repository. Do not commit credentials, API keys, tokens, passwords, private client material, personal financial data, private correspondence, unpublished security details or sensitive operational data.

Role and permission manifests describe **classes of authority**, not secrets. Production credentials and live sensitive evidence stay in approved systems outside this repository.

If sensitive content is committed, treat it as an incident: restrict exposure, rotate affected secrets where applicable, preserve an incident record, and invoke the K8 emergency workforce/change-control path.
